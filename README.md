# DAW-Skeleton
This contains my final project.
It is a step sequencer that plays a snare sample on the third beat of every measure. It is coded in java and has an audio engine, timing clock, playback logic, looping, and a graphical user interface w/ a pause/play button.
The tools used are java, javaFX, threads, objects, and System.nanoTime()
These are the bare bones for a project that will be expanded on to become a working daw.
