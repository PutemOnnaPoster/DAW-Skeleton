# DAW-Skeleton
This contains my final project.
It is a step sequencer that allows a user to place notes for three tracks kick, snare, and hi-hat. It is coded in java and has an audio engine, timing clock, playback logic, looping, and a graphical user interface w/ a pause/play button and a restart button.
The tools used are java, javaFX, threads, objects, and an Animation Timer.
This is a functional Daw with minimal features.
